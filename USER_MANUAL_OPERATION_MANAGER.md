# Web Admin User Manual — Operation Manager

## Overview
This guide is for Web Admin users with the **Operation Manager** role. Operation Managers use the web portal to review inspections and trainings, monitor job progress, manage documents and media, and support operational decision-making.

Operation Managers do not need the mobile app; they work entirely in the web interface for oversight and approvals.

## Role Summary
An Operation Manager can:
- View jobs and job details.
- Review inspection and training submissions.
- Approve or reject submitted reports.
- Access documents and media assets.
- Monitor equipment records.
- Use chat for collaboration.
- View notifications.

Operation Managers cannot access:
- User management (Admins and Super Admins only)
- Audit logs
- Settings
- Live tracking (Super Admin only)
- Scheduling and renewals (Admins only)

## Main Navigation
The sidebar includes these sections for Operation Manager users:
- Dashboard
- Jobs
- Inspections
- Trainings
- Assets
- Documents
- Media
- Notifications

## Dashboard
The dashboard gives an operational summary:
- Job counts by status
- Submitted inspections and trainings awaiting review
- Recent operational activity

Use the dashboard to identify work items that require review or approval.

## Jobs
The Jobs page is essential for tracking job status.

Operation Manager capabilities:
- View job lists and job details.
- Search and filter jobs by status, type, branch, and client.
- Review inspection or training assignment details.
- Verify job progress, site information, and assigned teams.

Use Jobs to locate submissions that require action or follow-up.

## Inspections
The Inspections page supports report review and approval.

Operation Manager actions include:
- Browse inspection records.
- Filter by status such as submitted, approved, rejected.
- Open detailed inspection reports.
- Approve or reject inspections.
- Review notes and rejection reasons.

When approving, the system updates the job status accordingly.

## Trainings
The Trainings page is for reviewing training submissions.

Operation Manager actions include:
- Browse training records.
- View submitted training details.
- Approve or reject training reports.
- Review training notes and evidence.

This page is similar to Inspections but specifically for training work.

## Assets / Equipment
The Assets page allows access to equipment details.

Operation Managers can:
- Browse equipment records.
- Review linked jobs and media.
- Check asset status and history.

This helps verify that inspections and trainings are attached to the correct equipment.

## Documents
The Documents page provides access to supporting files.

Use it to:
- Search documents by title, category, and job.
- Open technical documents and attachments.
- Verify that evidence and procedures are available for review.

Documents support the quality and compliance review process.

## Media
The Media page lets Operation Managers inspect uploaded photos and videos.

Key actions:
- Browse media by job and upload date.
- Open images and videos for review.
- Confirm evidence quality before approval.

Media review is critical for approving or rejecting field submissions.

## Notifications
The Notifications page helps you stay informed.

You can:
- View recent notifications.
- Mark notifications as read.
- Use alerts to track submitted work and follow-up requirements.

Notifications keep the review process timely.

## Chat
Operation Managers can use Chat to collaborate with teams.

Use Chat to:
- Open conversations about jobs.
- Clarify submission issues.
- Communicate approval or rejection feedback.

Chat supports fast decision-making and follow-up.

## Common Operation Manager Workflows

### Review submitted inspections
1. Open **Inspections**.
2. Filter by **Submitted** status.
3. Open the inspection record.
4. Review notes, media, and documents.
5. Click **Approve** or **Reject**.
6. Enter a rejection reason if rejecting.

### Review submitted trainings
1. Open **Trainings**.
2. Filter by **Submitted** status.
3. Review the training report and evidence.
4. Approve or reject.

### Verify evidence before approval
1. Open **Media**.
2. Search for the job or inspection.
3. Review uploaded photos and videos.
4. Confirm details match the inspection or training.

### Use chat for clarification
1. Open **Chat**.
2. Select the job conversation.
3. Ask questions or request additional evidence.
4. Use chat threads to track decision discussions.

## Notes
- Operation Managers focus on quality control and approval.
- If a job is incomplete or evidence is missing, reject it with clear feedback.
- For user, settings, or audit access, contact an Admin or Super Admin.
- Use the web portal only; field workers use the mobile app for data entry and inspections.
