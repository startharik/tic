# Web Admin User Manual — Coordinator

## Overview
This guide is for Web Admin users with the **Coordinator** role. Coordinators work entirely in the web portal to support jobs, assets, clients, documents, media, and notifications.

Coordinators do not need the mobile app. This manual focuses on the pages and actions available only to web users.

## Role Summary
A Coordinator can:
- View and manage jobs.
- Access assets and equipment records.
- Open chat for collaboration with engineers and admins.
- Work with documents and media.
- Send and manage notifications.
- Manage clients and branches.

A Coordinator cannot access:
- User management (Admins and Super Admins only)
- Audit logs
- System settings
- Live tracking (Super Admin only)
- Scheduling and renewals (Admins only)

## Main Navigation
The sidebar includes these sections for Coordinator users:
- Dashboard
- Jobs
- Assets
- Chat
- Documents
- Media
- Notifications
- Clients
- Branches

## Dashboard
The dashboard provides a quick operational summary:
- Job counts by status
- Recent activity and job progress
- Notifications and important alerts

Use the dashboard to quickly understand workload and focus on active jobs.

## Jobs
The Jobs page is your central workspace.

Coordinator capabilities:
- Search and filter jobs by status, client, engineer, trainer, and branch.
- Open job details for any accessible work order.
- View assigned engineer/trainer, client, site, and status.
- Monitor job progress without editing restricted assignments.

Use Jobs to track open jobs and review job status across the operation.

## Assets / Equipment
The Assets page lets you manage equipment records.

You can:
- Browse equipment and asset details.
- Search by asset name, ID, or category.
- Open equipment records to view linked jobs or documents.

Coordinators can support field teams by ensuring asset information stays accurate.

## Chat
The Chat page is available to coordinators for collaboration.

Use Chat to:
- Open job-related conversations.
- Send messages to engineers, admins, and other stakeholders.
- Review message previews and unread counts.

Chat helps coordinators coordinate field work and clarify job details quickly.

## Documents
The Documents page is where you review and manage technical files.

Coordinator access includes:
- Viewing documents and folders.
- Searching document titles and categories.
- Opening documents in the browser.
- Reviewing document attachments used by field teams.

If you need to upload or organize documents, coordinate with your admin users to confirm permissions.

## Media
The Media page provides access to photos, videos, and other uploaded files.

Coordinator actions include:
- Browsing media by job or category.
- Viewing uploaded evidence and media assets.
- Downloading files for review.

Use Media to inspect evidence and confirm job documentation quality.

## Notifications
Coordinators can manage notifications from this page.

You can:
- Read and dismiss notifications.
- Send notifications to users when needed.
- Review unread alerts for jobs, documents, and media.

Notifications keep coordination tight between teams.

## Clients
The Clients page allows coordinators to manage customer records.

Use it to:
- Search clients by name or contact details.
- View client information, addresses, and contact persons.
- Add new clients if needed.

Client records support job creation and assignment.

## Branches
The Branches page allows coordinators to manage locations.

Use it to:
- View branches and branch details.
- Add new branches as your business grows.
- Edit branch names, addresses, and statuses.

Branch management helps route jobs and assign regional work correctly.

## Common Coordinator Workflows

### Track jobs across teams
1. Open **Jobs**.
2. Filter by status, branch, or assigned engineer.
3. Open job details to verify client, site, and assignment information.

### Review attachments and media
1. Open **Documents** or **Media**.
2. Search for relevant files by title or category.
3. Open files to verify evidence and documentation.

### Manage clients and branches
1. Open **Clients** or **Branches**.
2. Search for the record or click **Create New**.
3. Update contact details or branch information as needed.

## Notes
- Coordinator permissions are designed around coordination, not system administration.
- If you need access to users, settings, or audit reports, contact an Admin or Super Admin.
- Use the web portal only; field workers use the mobile app for inspections and job execution.
